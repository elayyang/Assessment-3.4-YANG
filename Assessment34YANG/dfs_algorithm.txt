
ASSESSMENT 3.6: DFS METHODS IN TREE

PREORDER TRAVERSAL
1. Start.
2. Check if the current node is empty.
3. Visit the Root node.
4. Traverse the Left subtree.
5. Traverse the Right subtree.
6. Stop.

INORDER TRAVERSAL
1. Start.
2. Check if the current node is empty.
3. Traverse the Left subtree.
4. Visit the Root node.
5. Traverse the Right subtree.
6. Stop.

POSTORDER TRAVERSAL
1. Start.
2. Check if the current node is empty.
3. Traverse the Left subtree.
4. Traverse the Right subtree.
5. Visit the Root node.
6. Stop.
